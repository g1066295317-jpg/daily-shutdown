# 每天定时关机

双击 **每天定时关机.exe** 使用。Windows 版，免安装，不需要 Python。

## 设置关机规划

1. 将程序放在长期保留的文件夹，打开后选择时、分。可以直接输入数字，也可用上下箭头或滚轮调整。
2. 点击时间卡片内的“重复”选项，选择下列方式之一，点击“确定”返回。
3. 点击主界面的“保存并启用”，重复方式和时间才会保存到 Windows 任务计划程序。

| 重复方式 | 执行规则 |
| --- | --- |
| 只执行一次 | 可选择具体日期，仅在该日执行一次；过期、错过或取消后不自动改到明天。 |
| 每天 | 每天执行，包含周末和节假日。 |
| 法定工作日 | 按中国大陆年度放假调休安排，排除普通周末和通知中的放假日期，包含调休补班日。 |
| 法定节假日 | **仅国务院通知中的放假日期，不包含普通周末。** |
| 周一至周五 | 固定每周一至周五，不考虑放假和调休。 |
| 自定义星期 | 周一至周日自由多选，至少选一天，不考虑放假和调休。 |

没有轮班制。程序仍只保存当前用户的一项关机计划；重新保存会更新这一项。

**所选时间表示开始 60 秒倒计时的时间。** 例如设为 23:00，在 23:00 提醒，约 23:01 发起普通关机请求。此版没有改变既有计划的时间含义。

旧版的每日时间和自启动项继续保留。未保存新规划前，旧计划继续按原来的每天执行。

## 法定工作日与节假日日历

内置 **2026 年**中国大陆日历，依据国务院办公厅《国务院办公厅关于2026年部分节假日安排的通知》（国办发明电〔2025〕7号，2025-11-04）。

来源：[中国政府网官方通知（已核对繁体页面）](https://big5.www.gov.cn/gate/big5/www.gov.cn/zhengce/content/202511/content_7047090.htm)。

- 2026 年包含 7 段放假区间及 6 个调休补班日。
- 普通周末不属于“法定节假日”模式；需要周末关机，请使用“自定义星期”。
- **未覆盖年份会跳过执行，不会猜测为普通工作日或节假日。** 当没有已知的下次日期时，界面会提示需要更新日历。
- 例如 2026 年 10 月 18 日以后，内置的该年通知中已没有后续放假日期，“法定节假日”模式会等待新的年度日历。
- 在“重复”窗口点击“导入日历…”选择 XML 文件。导入立即生效，对已保存的日历类规划也有效。请按官方通知核对日期；软件检查格式，不会自动替你认证导入文件的来源。
- XML 格式可参考 `src\assets\calendar-2026.xml`：修改根节点年份、Holidays 内的 Range 放假区间以及 Workdays 内的补班日期。文件声明的年份必须与其中全部日期一致，放假与补班日期不能重叠。
- 导入文件保存在当前用户 `%LOCALAPPDATA%\DailyShutdownHelper\calendars`，每年一份。内置日历无需联网。
- 新年度数据需要导入或更新软件，本版没有后台联网更新服务。

## 托盘与开机自动启动

- 打开“开机自动启动”开关后，当前用户每次登录 Windows 会自动启动软件并进入托盘。开关立即保存，与关机规划分别设置。
- 关闭或最小化主窗口会收进右下角托盘。单击图标打开窗口，悬停查看规划和状态，右键可查看下次时间、暂停或恢复、取消本次倒计时。
- Windows 可能将图标收进右下角的“显示隐藏的图标”（上箭头），可将其拖到通知区域。
- 绿色表示计划启用，灰绿色表示未启用、暂停或单次计划已结束；橙色表示倒计时、状态异常或日历待更新。右键文字区分具体状态。
- 重复双击程序会唤回已有窗口，不会反复创建主窗口和托盘图标。
- 自动启动只登记当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DailyShutdownHelper`，不需要保存密码。Windows 可能延后启动登录项；如果你在任务管理器中将它禁用，需要在系统中重新启用。
- 托盘的“退出软件（保留关机计划）”只关闭界面进程，Windows 仍按计划启动倒计时。“暂停计划并退出”会先暂停并取消本次倒计时。

## 取消、暂停、移除

- **取消本次倒计时**：点击提醒窗口的按钮或关闭提醒窗口；主窗口和托盘也有取消入口。只跳过这一回，后续按所选重复方式执行；单次模式没有下一回。
- **暂停计划 / 恢复计划**：保留原时间和重复方式。已过期的单次计划需要重新选择未来日期，再保存。
- **删除计划**：只删除关机任务并取消本次倒计时，自动启动项和导入日历保留。
- **移除全部配置**：主界面右下角入口。确认后取消倒计时、删除本软件的任务、自启动登记及本软件导入的年度日历，然后退出。程序文件、内置日历及无关软件配置会保留。若部分移除失败，软件会列出失败项目并保持打开，供你重试。
- **体验倒计时**：仅演示提醒流程，不会关机。

## 运行条件与移动程序

- 电脑开机且当前用户已登录时运行，锁屏仍属于已登录。
- 不唤醒睡眠中的电脑，不补执行错过的日期和时间。倒计时期间发生睡眠或进程长时间停止响应，也会跳过本次。
- 接电和电池下都可运行。日期和时间使用电脑本地时间；法定日历按中国大陆安排。
- 不强制关闭应用。请保存文件；如果有应用阻止关机，Windows 可能要求你处理。
- 移动程序后，从新位置打开并点击“保存并启用”；若自动启动已打开，也会更新其路径。
- 删除程序前可使用“移除全部配置”，确认软件退出后再删除程序文件。

## 源码与验证

`src\build.ps1` 编译软件和多尺寸图标，不启用计划。`src\verify.ps1` 运行完整验证，会创建并清理专用的临时测试任务、启动项和日历；测试动作只写标记文件，不关机。`-UnitOnly` 只运行本地规则测试。

本次完整验证 **93 项通过**，覆盖旧计划兼容、六种规划、调休日历、单次到期、自定义星期、跨午夜、原生任务保存读取、一键移除范围和界面。详见“验证结果.md”。没有通过真实关机或重新登录测试。

实现调用 `shutdown.exe /s /t 0`，60 秒倒计时由软件显示，避免使用会隐含强制关闭的系统延时参数。[微软 shutdown 文档](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/shutdown)。
