# 验证说明

本次发布前在 Windows 本机完成以下验证，没有实际执行关机或重启。

## 功能验证：93 项通过

- 旧每日计划兼容、单次过期、自定义星期、重复方式序列化、跨午夜及倒计时期间变更规划。
- 核对 2026 年七段官方放假区间边界、六个调休补班日、普通周末排除和未知年份跳过。
- 向 Windows 任务计划程序保存并读取六种规划；仅用写入测试标记文件的动作验证任务启动。
- 开机自动启动登记、程序路径引用、暂停、恢复、删除与清理。
- 一键移除使用独立临时配置验证，确认保留无关启动项和文件。
- 托盘状态、窗口关闭后后台运行、单实例唤回、取消倒计时与真正退出。
- 主界面、重复选择、自定义星期和演示窗口的渲染检查。

## 绘制与生命周期：37 项通过

在 100%、125%、150%、200% 四种控件尺寸下检查按钮、禁用按钮、文字按钮、开关和星期选择方块，验证旧背景像素完全覆盖。另检查托盘与窗口生命周期。

程序内缩放渲染不等同于所有显示器、显卡和 Windows 缩放组合的实机覆盖。

## 复现

```powershell
.\src\verify.ps1 -UnitOnly
.\src\verify.ps1

# 编译测试程序后，绘制验证的输出目录必须已存在
.\src\.build\Tests.exe --painting (Get-Location).Path
```

完整测试会创建并清理带 `DailyShutdownHelper-Test-` 前缀的专用测试任务和启动项，以及独立日历测试目录，不应修改现有用户计划。请勿把测试截图和编译产物提交到源码仓库。
