# 每天定时关机

一个清新简约的 Windows 定时关机工具，支持系统托盘、登录自动启动和六种重复规划。免安装，不需要 Python。

**源码已公开；Windows 便携包尚待上传。** · [详细使用说明](docs/usage.md)



## 功能

- 六种规划：只执行一次、每天、法定工作日、法定节假日、周一至周五、自定义星期。无轮班制。
- 按时显示 60 秒倒计时，可取消本次；不强制关闭应用。
- 关闭窗口后进入托盘，支持查看状态、暂停和恢复计划。
- 当前用户登录 Windows 后自动启动，可随时关闭。
- 一键移除关机计划、自启动项和导入日历，保留程序文件。

## 使用

1. 先按下方“构建与验证”生成 EXE；Windows 便携版下载包发布后会在本页补充入口。
2. 双击“每天定时关机.exe”，设置时间，并点击“重复”选择规划。
3. 点击“保存并启用”。需要登录自动启动时，打开对应开关。

所选时间是**开始倒计时**的时间：例如设为 23:00，在 23:00 提醒，约 23:01 发起关机请求。

仅电脑开机且当前用户已登录时执行；锁屏仍会执行。不会唤醒睡眠中的电脑，也不会补执行错过的时间。应用阻止关机时，需要用户处理。

## 节假日日历

内置 2026 年中国大陆放假及调休安排，来源为[国务院办公厅官方通知](https://big5.www.gov.cn/gate/big5/www.gov.cn/zhengce/content/202511/content_7047090.htm)。

- **法定工作日**考虑调休补班；**周一至周五**不考虑调休。
- **法定节假日**仅包含通知中的放假日期，不含普通周末；普通周末可自行选择星期。
- 新年度通过“重复 → 导入日历…”导入 XML。格式参考 [calendar-2026.xml](src/assets/calendar-2026.xml)。
- 未覆盖的年份会跳过执行，不会推测工作日或节假日。本版不提供后台联网更新。

## 构建与验证

运行环境：Windows、.NET Framework 4.x、Windows 任务计划程序。

在项目根目录打开 PowerShell：

```powershell
.\src\build.ps1
```

生成 `src\每天定时关机.exe`。构建脚本同时生成程序及托盘所需的多尺寸图标。

```powershell
# 仅本地规则测试，不更改系统配置
.\src\verify.ps1 -UnitOnly

# 完整测试：使用专用临时任务、启动项与日历，完成后清理
.\src\verify.ps1
```

测试动作只写标记文件，不执行关机。已完成 93 项完整检查及 37 项绘制和窗口生命周期检查；没有自动执行真实关机或重启。详见[验证说明](docs/verification.md)。
